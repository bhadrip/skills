# What not to repeat without new evidence

These are reusable lessons, not a universal prohibition on a tool or technique.
The original subject data, measurements, experiment outputs and history are
intentionally absent from this public package.

| Stalled pattern | Why it can fail | Better next test |
|---|---|---|
| Many tiny changes to a visibly wrong generic head | The identity foundation constrains every later edit | Compare one meaningfully different complete-head foundation |
| Generated clay turnaround as the only conditioning | It can reconstruct the invented portrait rather than the person | Use actual photographs; keep stylization an explicit choice |
| Relative Portrait disparity treated as a metric face | Quantization and scale/offset ambiguity omit fine anatomy | Retain broad form evidence, inspect real camera metadata |
| Independent view reconstructions fused as a scan | Expressions/cameras or correspondences may disagree | Validate rigid registration; otherwise use views as sculpt constraints |
| A slightly better reused landmark/embedding score | Camera fitting, reuse and texture can hide identity errors | Fixed neutral whole-head review and user recognition |
| More surface smoothing after a ring survives | Masks may exclude it; folded topology may remain | Locate it, inspect topology, replace the local closed volume if needed |
| Global mouth setback | It can create shelf-shaped lips | Redistribute local curvature/volume while preserving the seam |
| Corrugated hair cap or crown starburst | Periodic/radial relief is not deliberate comb flow | A coherent mass plus a few independently curved attached locks |
| Cropped eye/nose tiles grafted onto the head | Anatomical seams and view inconsistency can dominate | Regional edits in the coherent head; preserve neighboring anatomy |
| A valid mesh labeled a likeness win | Topology and recognition are separate | Require visual review before promotion |
| Smooth shader used to hide remnants | Print geometry has not changed | Inspect actual silhouettes, detail and export |
| Slicer exit code or empty warning summary alone | Internal warnings or absent/incorrect output can be missed | Raw logs, actual layers/support paths and 3MF re-import |
| Repeated checks instead of a handoff | Validation drifts into a new research project | Stop once scoped visual/geometry/slice gates pass; report remaining physical tests |

For each new trial record: immutable parent, hypothesis, exact operation and
parameters, protected regions, actual evidence, decision and stopping rule.
Never rewrite a failed experiment into an apparent success.
